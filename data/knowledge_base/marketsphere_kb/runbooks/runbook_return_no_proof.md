# Returns Without Proof of Purchase

*Last updated: 2024-09-15*

## When This Applies

Customer wants to return an item but:
- Doesn't have an order number
- Email doesn't match any account
- Claims it was a gift but has no gift order info

## Verification Process

1. Search by customer name across multiple emails (people sometimes have multiple accounts).
2. Ask for any reference: shipping address, approximate date, payment method last 4.
3. Search by product + approximate date range.

## Decision Framework

**If verifiable through alternative means**:
- Treat as normal return.
- Update account/email mapping in CRM if discrepancy explained.

**If gift, recipient not the buyer**:
- Ask for the giver's name and email.
- Look up the gift order and process as normal gift return.
- Refund goes to the giver's original payment method OR can be issued as store credit to the recipient (customer's choice).

**If completely unverifiable**:
- Item must show evidence of MarketSphere origin (our packaging, our logo, etc.).
- Offer store credit at current sale price (not original purchase price) as a goodwill measure.
- Do not refund cash for unverifiable items.

## Note on Fraud Patterns

Be alert to: serial numbers from items reported stolen, repeated unverifiable returns from same address, high-end items with no purchase trail. Escalate to loss prevention.
