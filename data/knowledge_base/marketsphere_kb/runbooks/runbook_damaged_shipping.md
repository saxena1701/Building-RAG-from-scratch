# Handling 'Damaged in Shipping' Reports

*Last updated: 2024-09-15*

**Audience**: Tier 1 support agents.

## Initial Assessment

When a customer reports an item arrived damaged:
1. Empathize with the customer and apologize for the experience.
2. Request photos of: the item, the packaging, and the shipping label.
3. Verify the order in the CRM (order ID, delivery date).
4. Confirm the report is within the 7-day reporting window.

## Resolution Tree

**If photos clearly show damage caused in transit**:
- Issue full refund OR replacement at customer's choice.
- Always offer expedited shipping on replacement at no charge.
- Issue prepaid return label for damaged item if value > $25; otherwise, customer keeps item.
- Document with damage category code DMG-TRANSIT in the order notes.

**If damage appears to be manufacturing defect, not transit**:
- Same resolution but use code DMG-MFG.
- File supplier quality report (form Q-101) for items > $50.

**If unclear from photos**:
- Request additional photos showing specific angles.
- If customer can't provide, default to customer's account: trust customers in good standing (3+ year accounts, < 5% return rate) and process.

## Escalation Triggers

- Multiple damage claims from same customer in 30 days (potential fraud)
- Item value > $500
- Bulk shipment damage (multiple items)
- Carrier-side issue requiring carrier claim
