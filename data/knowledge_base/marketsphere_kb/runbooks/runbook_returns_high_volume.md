# High-Return-Rate Customers

*Last updated: 2024-09-15*

## Identification

Flagged automatically when an account exceeds:
- 40% return rate over last 12 months, OR
- 60% return rate over last 6 months, OR
- Returns of items showing wear (clear use indicators)

## First Touch

When an account first triggers the flag:
1. Internal note only; customer does not see the flag.
2. Review return reasons - some categories naturally have high return rates (apparel, especially shoes).
3. If returns are legitimate (size issues with apparel), no action needed.

## If Pattern Continues

After 30 days of continued high return rate:
1. Send a customer service email offering size guidance, product consultation, or fit help.
2. Often this is a customer who needs help finding what they want, not a fraudster.

## If Pattern is Abusive

Signs of actual abuse:
- Items returned with clear wear (worn shoes, washed clothes)
- Items with non-original tags
- Items with parts missing
- "Wardrobing" pattern (events visible in social media followed by return)

For abusive patterns:
1. Notify customer in writing that future returns require additional inspection.
2. Specific abuse may warrant account review or closure.
3. Coordinate with loss prevention.
