# Runbook: Processing Electronics Returns (Legacy)

*Last updated: 2023-03-12*

## Internal Runbook: Electronics Returns

**Audience**: Tier 1 and Tier 2 support agents.

### Eligibility Check

When a customer requests to return an electronics item, verify:
1. Order date - must be within **14 days** for opened electronics, 30 days for sealed.
2. Customer has receipt or order number.
3. Item is not on the "no-return electronics" list (see Appendix B of legacy SOP).

### Processing Steps

If within window:
- Generate return authorization in the legacy returns portal.
- Email customer the prepaid label.
- Note in CRM: "RMA issued per legacy electronics policy."

### Restocking Fees

Standard 20% restocking fee for opened electronics returns. Waive if defect verified.

### Escalation

Escalate to Tier 3 if:
- Customer disputes the 14-day window
- Item value exceeds $500
- Customer is a Premier member
