# Exchange Policy

*Last updated: 2024-09-05*

## Same-Item Exchange
You can exchange an item for a different size, color, or variation within the standard return window. Exchanges are processed at no additional cost provided the price is the same.

## Different-Item Exchange
For exchanging an item for a different product, we recommend processing a return and a new order. This ensures the new item ships immediately rather than waiting for the original to be received and processed.

## Pricing on Exchanges
If the exchange item costs more, the difference is charged. If it costs less, the difference is refunded.

## Eligible Items
Exchanges follow the same eligibility rules as returns. Final sale and perishable items are not eligible.
