# Can I use multiple promo codes on one order?

*Last updated: 2024-09-01*

## Question

Can I use multiple promo codes on one order?

## Answer

Only one promo code per order, with one exception: a free shipping code can be combined with one other promo code (such as a percentage-off code). Promo codes do not stack with employee discounts, bulk discounts, or other promo codes.
