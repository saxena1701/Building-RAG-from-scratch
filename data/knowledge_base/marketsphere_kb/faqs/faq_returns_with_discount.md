# If I used a promo code, what do I get back on a return?

*Last updated: 2024-09-01*

## Question

If I used a promo code, what do I get back on a return?

## Answer

Refunds for items purchased with a promo code are pro-rated. If you used a 20% off code and return one of multiple items, the refund is for the price you actually paid for that item (80% of list price), not the list price.
